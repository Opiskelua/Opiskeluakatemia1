# Finnish matriculation exam, English long syllabus (EA): what "Grammar and Vocabulary" actually tests

Compiled 2026-10-30 from YTL answer keys (hyvän vastauksen piirteet, HVP) and the public exam viewer copies on Yle Abitreenit. Purpose: our Opiskeluakatemia exercises should test the same things, in the same formats, with the same kinds of distractors.

**How sure each part is**
- **[V] Verified**: I read the exam text, the gap context, every option and the key.
- **[K] Key-only**: I read the official answer key, including any cue word (Finnish word, English base form or grammar term), but not the MC options. The tested point is my reading of the answer and its cue.
- **[I] Inferred**: my interpretation, for example why a distractor exists or what a trend means.

Gap contexts below are paraphrased or quoted in a few words only. No full texts are copied.

**Constants [V]:** every MC cloze is a continuous authentic text (Guardian, FT, BBC, inews, Time, academic prefaces and encyclopedia entries) adapted by YTL. Productive answers are graded against a list of accepted variants, and the key says "Myös muut oikeat ilmaisut hyväksytään" (other correct expressions are also accepted).

## 3. Item-by-item catalogue

Format codes: **MC4/MC3** = drop-down cloze with 4 or 3 options. **P-FI** = productive gap with a Finnish word or phrase to translate in context. **P-EN** = productive gap with an English base form to inflect. **P-GR** = productive gap with a grammar-term cue ("prepositio", "pronomini", "apuverbi", "numeral", "characterize + preposition") or "(No clue)". **SYN** = choose the option that means the same as the underlined word. **BANK** = word bank. **REG** = register replacement. **ERR** = one-word error correction.

Notation: answer **in bold**, then the distractors.

### 2018 autumn [V]
**16 "Art of Living Car-lessly" (MC4, 9 p)**
1. lend/borrow confusion: friend **lent** me her flat / adopted / borrowed / received
2. -ing participle clause after a comma ("…, starting with 'Please move it…'"): **starting** / start / starts / started
3. word formation, gerund compound by analogy with "pet-sitting": park-**sitting** / sit / sits / sitter
4. verb + object + to-infinitive, distractors are con- lookalikes: **convinced** me to sell / concluded / contributed / constrained
5. preposition after a verb: charge £200 **for** / in / on / with
6. conjunction "Except (that)", distractors are lookalikes: **Except** / Expect / Exempt from / Excluding
7. indefinite pronoun in a question: is there **anything** dumber / something / nothing / everything
8. passive gerund after a noun: machines **being left** idle / left / be left / been left
9. collocation "make the point that": **made the point** / raised the question / nailed down / drew attention

**17 "Nigeria's Nightmare" (productive, 10 p)**
Cues: vähemmän → **fewer/less** (dollars); prepositio → attack **on/against**; cut → **cutting** (participle clause); öljytulot → **oil revenue**; valuutta → **currency**; koillinen → in **the northeast** (article + compass noun); elect → **was elected** (passive); elvyttää → **revive/boost**; ei hyväksynyt → **didn't approve**; "ennen kuin toukokuussa" → **until May** (not…until, not *before*).

## 5. How distractors are built

Each pattern is followed by real examples from the [V] exams. Use these as templates for our distractor generator.

1. **Same lemma, different form**. This is the most common pattern, about 30% of MC gaps. All options are forms of one verb, so the student must pick finite or non-finite, tense, voice or agreement. Examples: *aim / aims / aimed / aiming*; *continue / continues / continued*; *governs / will govern / govern*; *rose / rise / risen*; *brim / to brim / brimming*; *left / have been left / have been leaving*; *encourages / encouraged / to encourage*; *was removed by / were to remove / has removed*.
2. **Same word family, different class or suffix**: *detracting / detractor / detractive / detracted*; *intelligibility / intelligence / the intellectual*; *regarding / regardless / regarded*; *recognizably / recognizing / recognized*; *debating / debatably / debate*; *common / in common / commonly*.
3. **Spelling or sound lookalikes with unrelated meanings**: *distract / distrain / distance / distort*; *avid / vivid / tepid*; *deliverance / delirium / deliberation*; *succession / smothering / suspense*; *complete / compliment / complement*; *Except / Expect / Exempt from*; *hail / hand / hold*; *substantially / superficially / sedentarily*; *a speciality / specially / especially*. Synonym tasks use the same trick: *distorts / displaces / dissembles*, *decode / delude / deflate*, *inborn / involved / insidious*, *pay in / pay off / pay up*.
4. **Closed sets of grammar words**: prepositions (3–4 common ones, sometimes plus "–"); articles (*Ø / a / an / the*); relatives (*what / that / which / —*, *who / which / what*); quantifiers (*many / few / much*, *either / neither / each / nor*); auxiliaries (*has / have / has been / have been / nothing*).
5. **Finnish-interference calques** [I: the distractors are verified, the Finnish-interference reading is mine]: *aged by 12 / aged at 12* (from *12-vuotiaana*); *the 31-years-old / 31-year old*; *in the late 2022 / in later 2022*; *millions people / millions of the peoples*; *deal in / out*; *enter into / to / at*; *mistaken by / with*; *a underprivileged*; *the know*; *a horizon / the horizon*. Many target errors Finnish students actually make with articles, hyphens and prepositions.
6. **A fixed phrase against near-miss literal variants**: *in the widest sense* vs *for a wider / through a wide*; *as such* vs *so be it / whereas*; *Aside from* vs *Beside / As for*; *at times* vs *between times / in time / on time*; *not unlike* vs *likely / unlikely / unlike*; *made the point* vs *raised the question / nailed down / drew attention*.
7. **Agreement traps with a distant or plural subject**: *operas … remains / remain / remained*; *shifts in intellectual fashion that brought … to the forefront was reflected / were reflected*; *laws … that governs / govern*.
8. **Word order and correlatives**: *should the process / the process should / would the process*; *neither … nor / both … and / as … as / either … or*.
9. **Plausible-but-wrong meaning in synonym MC**: the distractors fit the sentence grammatically but carry the wrong sense or attitude: *ominous* vs *generous / curious*; *hastened* vs *followed / blocked*; *proportion* vs *opening / breakage* (other senses of "fraction"); *massive* vs *mediocre / multiple*.
10. **Option count**: 4 options in 2018–2019 [V]. 3 options in every MC cloze and synonym task from 2023 autumn to 2026 autumn [V]. 2020–2023 spring is unknown [K]. Word banks have 6 words for 5 gaps or one extra word per set. 2025 S had one 5-option set reused for 6 gaps.

## 7. Writing task (Part 4, Production)

**Format, constant since 2018 autumn [V]**
- One composition, chosen from **4 prompts**, worth **99 p of 299**. It is graded with the YTL criteria table for languages (content, coherence, vocabulary, structures).
- Length **700–1,300 characters, excluding spaces and line breaks**. That is roughly 120–220 words [I]. Since about 2023 the instructions add: "recommended minimum is 700… If you write less, it is very difficult to fulfil task requirements". Going over 1,300 characters costs a points deduction ("Ylityksestä seuraa pistevähennys") [V].
- Task-specific deductions in the keys [V]: **−2 p** if a letter lacks its opening or closing (2026 K "This is me!" application); **−5 p** if arguments or reasons are missing (2026 K film essay); **−5 p** if a fake-news text has no concrete example (2021 S).
- In 2022 there were also short productive answers of at most 150 characters in the reading section [K]. These are not part of the composition.
- Paper era, before 2018: the long-syllabus composition was 150–250 words [I: from general knowledge; I did not open a paper-era booklet to confirm].
