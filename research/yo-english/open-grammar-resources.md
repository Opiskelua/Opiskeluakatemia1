# Open / openly licensed English grammar resources for Opiskeluakatemia

Researched 2026-10-30. Context: we sell YO English prep (abikurssi). Grammar exercises are generated by Gemini (multiple-choice cloze: articles, prepositions, tenses, and so on, with Finnish explanations). See `opiskeluakatemia/AI_GENERATED_GRAMMAR_EXERCISES.md`. **We are a commercial product**, so anything marked NC (non-commercial), "research only" or "unclear" cannot ship in the product without written permission.

How to read the license column:
- **OK**: commercial use allowed. The conditions are listed.
- **NC**: non-commercial only. Not usable in our product.
- **Unclear**: no license found. Treat it as all rights reserved.

ShareAlike note: CC BY-SA means that if we **copy or adapt the text** (explanations, example sentences), the derived text must also be CC BY-SA, with attribution. Using BY-SA data **internally as a validator or lookup**, without republishing it, does not trigger ShareAlike in practice. Even so, keep an attribution page (`/lahteet`). The EU sui generis database right also exists, which is one more reason to stay within the licenses rather than relying on "facts aren't copyrightable".

## 3. Grammar checkers as validators

| Tool | License | Notes |
|---|---|---|
| **LanguageTool** (self-hosted HTTP server) | **LGPL 2.1+** for the core and the rule files in the repo, including `grammar.xml`. https://github.com/languagetool-org/languagetool | Java 17. Install with `brew install languagetool` or run the server jar (https://dev.languagetool.org/http-server). English has thousands of XML pattern rules (about 3,700 grammar rules as of v5.2) plus Java rules. Optional **n-gram data** (about 8 GB, SSD recommended, https://dev.languagetool.org/finding-errors-using-n-gram-data) adds homophone and confusion-pair detection. It is derived from Google Books Ngram (CC BY 3.0), and LT does not state a license for its packaged form, so treat that as unclear. **The self-hosted version lacks the "AI-based rules" of the cloud product.** Running it as an unmodified server over HTTP raises no LGPL obligations for our Next.js code. |
| ERRANT | **MIT**. https://github.com/chrisjbryant/errant | Not a checker. It aligns an original and a corrected sentence and labels the edit type (M:DET, R:PREP, R:VERB:TENSE, R:VERB:SVA...). Useful to classify **student answers or essay corrections** into error categories for skill-profile tracking. |
| Python wrapper `language_tool_python` / Rust port `nlprule` | GPL-3.0 / MIT-Apache (wrappers) | Not needed. Call the HTTP API from a Supabase edge function or a small VPS. |

**LanguageTool as a validator for Gemini output.** Pros: it is deterministic, cheap, offline and has no per-call cost. It reliably catches agreement errors (a/an, SVA, "more better", doubled words, common confusions such as its/it's and then/than), typos and punctuation. Cons: it has low recall on the errors that matter most for cloze **ambiguity**. It cannot tell you that "I ___ here since 2019" has two acceptable answers, and it misses many tense, article and preposition choices that are only wrong in context. It also produces false positives on stylistic rules, so whitelist rule categories (GRAMMAR, TYPOS, CONFUSED_WORDS, and drop STYLE). Recommended check: substitute the **correct option**; it must yield 0 GRAMMAR or TYPOS matches. Substitute each **distractor**; if any yields 0 matches **and** a second Gemini "is this also acceptable?" judge says yes, the item is ambiguous, so reject or regenerate it. Treat LT as a necessary filter, not a sufficient one.

## Recommendation: top 5 to adopt

1. **LanguageTool (self-hosted, LGPL 2.1+)**: the quality gate for every Gemini item. Run the server with the docker image or brew on a small VPS or Fly.io. In the generation route, check the stem with the correct answer filled in (must have 0 GRAMMAR or TYPOS hits), and check each distractor substitution. A distractor that passes cleanly goes to a second "is this also correct?" LLM judge, and ambiguous items are rejected or regenerated. Start without n-grams, and add them later if confusion-word errors show up. Cost: about 1 GB RAM, with no licensing effect on our code.
2. **CEFR-J Wordlist + Grammar Profile (free commercial use, citation) + Octanove C1/C2 (CC BY-SA)**: the open replacement for EVP/EGP/Oxford 3000. Put it into Supabase. (a) Constrain Gemini prompts: "use only vocabulary ≤ B2 except the target item". (b) Post-check generated sentences for out-of-level words. (c) Tag every exercise with a CEFR grammar item so the skill profile maps to levels.
3. **Tatoeba eng↔fin pairs (CC0 subset first, then CC BY 2.0 FR with attribution)**: a bank of human-written sentences. Cloze items built from real sentences are more natural than generated ones, and Finnish translations give us ready translation and "spot the Finglish" exercises. Filter by native-speaker owner, length and LT-clean, and keep the sentence ID and author for attribution.
4. **Open English WordNet (CC BY 4.0) + Wiktionary/kaikki extract (CC BY-SA)**: the verb-pattern and phrasal-verb backbone. Build a JSON table `{verb: {to_inf, ing, that_clause, preps[], phrasal_particles[]}}` from OEWN frames and Wiktionary tags. Use it to (a) validate that the "correct" answer in verb + to/-ing and preposition items is supported by the table, and (b) seed phrasal-verb sets, intersected with a frequency list. Keep the table internal, and if we publish definitions copied from Wiktionary, mark those pages CC BY-SA.
5. **ERRANT (MIT)**: classify mistakes in students' free-text answers and essays, compared against a Gemini correction, into standard error types. This gives the skill profile and "your weak areas" an objective taxonomy aligned with what research shows Finnish learners struggle with (articles, prepositions, tense).

Honourable mention: **Advanced Academic Grammar for ESL Students (CC BY)** is a human-written, adaptable source of explanations and exercise models for passive, articles and clauses. It is worth mining by hand when we write the grammar theory pages.

**Do not use in the product** (NC, unclear, or explicitly anti-AI): EGP/EVP, Oxford 3000/5000, the BEA-2019 corpora, W&I 2024, Lang-8/cLang-8, OpenStax Writing Guide, UD GUM, the Academic Collocation List, and the PHaVE/PHRASE lists (unless the authors grant permission). ICLE-FIN is the only Finnish-learner English corpus, and it would require a negotiated (paid) license.
